# Derived Quantities

Pure NumPy functions for field-level derived quantities. All functions operate in normalized units ($\mu_0 = \epsilon_0 = 1$ in PIC, $\mu_0 = 1$ in MHD). Arrays in, arrays out — no FieldDataset dependency.

See [Equations Reference](../equations.md) for the full physics and conventions behind these quantities.
